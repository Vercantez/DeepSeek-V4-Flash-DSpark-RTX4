# Stock SM120 TP4+EP validation

Date: 2026-08-10

Hardware: one AWS `g7e.24xlarge`, 4x RTX PRO 6000 Blackwell Server Edition,
PCIe-only. The instance was isolated from production routing.

## Runtime

- vLLM 0.25.1
- FlashInfer Python 0.6.14 with FlashInfer cubins 0.6.13
- DeepSeek V4 Flash checkpoint, 155.43 GiB
- TP=4 and expert parallelism enabled
- FP8 KV cache, block size 256
- Marlin MXFP4 MoE backend
- DCP=1; speculative decoding disabled
- max model length 262,144; GPU memory utilization 0.90
- async scheduling, prefix cache, and full/piecewise CUDA graphs enabled

Cold engine initialization took 310.40 seconds. It included DeepGEMM warmup,
FlashInfer SM120 sparse-MLA autotuning, and capture of 51 mixed and 51 decode
CUDA graphs.

## Capacity and correctness

- Model allocation: 38.09 GiB per GPU
- Resident allocation after warmup: approximately 90.7 GiB per GPU
- Available KV memory: 43.02 GiB per GPU
- Effective KV pool: 2,917,131 tokens
- Capacity ratio: 11.13 full 262,144-token contexts
- Exact deterministic canaries: 162/162 passed across repeated c1, c16, and
  c64 waves
- Every performance request through c512 completed successfully
